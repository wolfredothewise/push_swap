This project its about of sorting numbers with a series of instructions(pa/b, sa/b, ra/b...) in the less amount of operations possible.You will see stacks, linked lists, args parsing and algorithm logic in this project.

•To test the project, you should do "make", then a executable file appears and you execute it with the numbers you want to sort. Moreover, you can use a checker to see if its valid, "NUMS=$(shuf -i 1-1000 -n 100 | tr '\n' ' ')                     
./push_swap $NUMS | ./checker_linux $NUMS".
